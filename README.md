# MonoFinance

Minimalist, stylish black and white interactive finance tracking dashboard for PC.

## Features

- Dynamic balance, income, expense, and savings metrics.
- Sleek, custom-rendered SVG trend line charts tracking income and expenses.
- Interactive transaction ledger with categorization badges and filters (All, Income, Expenses, Savings).
- Custom savings goal tracker with real-time percentage progress bar.
- Clean monochromatic dark and light themes with instant toggling.
- Fully local persistence using `localStorage`.

## Tech Stack

- HTML5
- CSS3 (Vanilla CSS with variables and micro-animations)
- JavaScript (Vanilla JS, client-side SPA)
